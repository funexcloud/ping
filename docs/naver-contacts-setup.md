# 네이버 주소록으로 명단 올리기 (내보내기 파일)

이 앱은 **네이버 클라우드·메일의 OAuth 연락처 API**로 주소록을 직접 읽지 **않습니다**.  
브라우저에서 할 수 있는 방식은 **네이버에서 내보낸 CSV(또는 엑셀) 파일을 선택**해, 기기 안에서만 파싱한 뒤 발송 대상을 고르는 흐름입니다. (Google 연락처만 People API·OAuth를 사용합니다.)

---

## 1. 네이버에서 주소록 내보내기

네이버 메일·주소록 화면은 수시로 바뀔 수 있으니, 아래는 **대표적인 경로**입니다. 메뉴 이름이 조금 달라도 «주소록», «내보내기», «가져오기/내보내기»류를 찾으면 됩니다.

1. PC 브라우저에서 [네이버 메일](https://mail.naver.com) 등에 로그인합니다.
2. **주소록**(연락처) 메뉴로 이동합니다.
3. **내보내기**(또는 CSV 저장 / 연락처 백업)를 선택합니다.
4. 형식이 선택 가능하면 **CSV**를 고릅니다. (엑셀만 된다면 `.xlsx`도 앱에서 읽을 수 있으나, 한글 깨짐 이슈는 CSV+CP949 쪽이 안정적인 경우가 많습니다.)
5. 저장된 파일을 **휴대폰으로 전송**(이메일 첨부, 메신저, 클라우드 등)하거나, 같은 기기에서 바로 다음 단계로 진행합니다.

> **참고:** 네이버 앱 단독 화면만으로는 웹과 동일한 «전체 CSV 내보내기»가 없을 수 있습니다. 그럴 때는 **PC 웹에서 내보내기** 후 파일을 모바일로 옮기는 방법이 확실합니다.

---

## 2. 파일 형식과 인코딩

| 항목 | 설명 |
|------|------|
| **권장** | 확장자 `.csv`, 네이버 기본 인코딩(**EUC-KR / CP949**) |
| **앱 동작** | `index.html`은 CSV를 SheetJS로 열 때 **CP949(949)** 로 먼저 읽고, 실패하면 UTF-8로 재시도합니다. |
| **엑셀** | `.xlsx` / `.xls`도 선택 가능합니다. |

Excel에서 CSV를 «다른 이름으로 저장»할 때 **UTF-8**로 바꾸면 앱의 두 번째(UTF-8) 시도로도 읽힐 수 있지만, 가급적 **네이버에서 받은 원본**을 그대로 쓰는 것이 안전합니다.

**기본 파일명 예:** PC에서 내려받으면 `NAVER_Contacts.csv`처럼 저장되는 경우가 많습니다. 첫 줄 헤더에 `휴대폰번호`, `성`, `이름` 열이 있으면 앱이 그대로 인식합니다.

---

## 3. 앱에서 파일을 올리는 경로

1. **대량 발송(부고/답례 등)** 플로우를 진행해 «연락처 가져오기» 단계까지 갑니다.  
   화면 제목 예: **«연락처는 어디서 가져올까요?»**
2. **Google 연락처** 대신 **«네이버 주소록 파일»**(내보낸 CSV·엑셀 선택) 버튼을 누릅니다.  
   (코드상 `loadNaverContacts()`는 동일하게 이 버튼과 같은 파일 선택을 띄웁니다.)
3. 파일 선택창에서 네이버에서 내려받은 **주소록 CSV(또는 엑셀)** 를 고릅니다.  
   - 일부 안드로이드/iOS에서는 목록에 `.csv`가 안 보일 수 있습니다. 선택기 상단의 **«모든 파일»**·**«다운로드»** 등을 이용해 보세요.
4. 파일이 분석되면 **번호가 들어 있는 열**을 기준으로 건수가 잡히고, 이후 단계에서 **제외할 연락처**를 고를 수 있습니다.

---

## 4. 번호·이름 열 인식 기준

첫 행(헤더)에서 아래에 해당하는 **열 이름**을 찾습니다.

- **번호:** `휴대폰`, `휴대폰번호`, `휴대전화`, `Mobile`, `phone`(대소문자 무관), 정확히 `전화번호` 등  
- **이름(표시용):** `이름`, `성명`, `표시 이름`, `고객명` 등 일반적인 한국어/영어 표기. 네이버 기본 내보내기처럼 **`성`·`이름`이 나뉘어 있으면** 앱이 합쳐서 표시 라벨로 씁니다.

**«휴대폰/전화번호 열을 찾지 못했습니다»** 가 나오면:

- 네이버 내보내기 **원본 CSV**를 다시 선택했는지 확인합니다. (Excel에서 열 순서만 복사해 붙인 파일은 헤더가 달라질 수 있습니다.)
- 헤더에 `휴대전화`·`휴대폰`·`전화번호` 중 하나가 있는지 메모장/스프레드시트로 확인합니다.

## 5. 흔한 오류와 점검

| 증상 | 점검 |
|------|------|
| **한글이 깨져 보이거나 행이 이상함** | 네이버 기본 CP949 CSV를 그대로 쓰는지, 중간에 UTF-8로만 저장된 파일로 바뀌지 않았는지 확인합니다. |
| **유효 번호 0건** | 번호 열에 `010-1234-5678` 형태·하이픈 없는 숫자 등이 들어 있는지 확인합니다. 국제번호(`+82…`)는 앱에서 `0`으로 시작하는 국내형으로 바꿔 인식합니다. |
| **모바일에서 파일이 안 보임** | 다운로드 폴더·「모든 파일」 표시, 다른 브라우저(Chrome/Safari)로 시도합니다. |

주소록 파일을 **Firebase Storage에 저장**하는 배포 구성을 쓰는 경우, 브라우저에서 업로드가 막히면 **Storage CORS** 설정이 필요합니다. 운영 절차는 루트의 `firebase-storage-cors.json`과 [deployment-playbook.md](./deployment-playbook.md)의 **Storage CORS** 절을 참고하세요. (버킷 이름·도메인은 실제 프로젝트에 맞게 적용합니다.)

---

## 6. 정리

- **네이버:** 웹에서 주소록 **내보내기(CSV 권장)** → 기기에 저장.
- **앱:** «연락처는 어디서 가져올까요?» → **«CSV·엑셀 파일»** → 해당 파일 선택.
- **API 연동 없음:** 네이버 측 OAuth·REST 연락처 API를 붙이지 않았다는 뜻입니다. 필요하면 별도 백엔드 연동 설계가 필요합니다.

Google 연락처 OAuth 설정은 [google-contacts-setup.md](./google-contacts-setup.md)를 참고하세요.
