# 제품 포지셔닝

## PING vs 일반 SMS 대행 사이트

| | 일반 문자 사이트 | PING |
|---|----------------|------|
| **목적** | 건수만큼 문자 발송 | **부고 한 건** 전체 흐름 |
| **입력** | 수동 붙여넣기 | **부고 URL import** · Google/CSV |
| **과금** | 입력 건수 | **유효 번호** 기준 (110원/건) |
| **결제** | 선충전·계좌 | **토스** · 무통장 |
| **발송 후** | 없음 | **상태 추적** · 부의금 · 안심 링크 |
| **링크** | 원본 URL 노출 | **`/s/{token}`** 서명·만료 |

PING은 **저렴한 SMS API**가 아니라 **장례 커뮤니케이션 vertical SaaS**입니다.

---

## 신뢰 포인트 (마케팅·약관)

- 안심 부고 링크 — JWT 서명, 발인+유예 만료
- 발송 상태 — 접수 → 세팅중 → 완료 (실패·부분실패 별도 표기)
- 투명 과금 — 유효 건수 기준
- 사업자 표기 — 한국AIBC융합원, 통신판매업 신고

**주장하지 않을 것:** 미등록 발신번호 발송, 100% 도달 보장, 최저가 SMS.
