# PING Wiki 원본 (저장소 내)

GitHub **Wiki 탭**에 보이는 내용과 **자동 연동되지 않습니다.**  
이 폴더를 Wiki git 저장소(`funexcloud/ping.wiki`)에 **별도로 푸시**해야 합니다.

## 지금 Wiki URL이 비어 있거나 README만 보일 때

1. **이 폴더가 GitHub `main`에 없음** → `docs/wiki/` 커밋·푸시 후  
   https://github.com/funexcloud/ping/tree/main/docs/wiki 에서 먼저 읽을 수 있음
2. **Wiki 기능 미활성** → GitHub 저장소 **Settings → Features → Wikis** 켜기
3. **Wiki 첫 페이지 미생성** → **Wiki** 탭 → *Create the first page* (Home 한 줄이라도 저장)
4. **Wiki git 푸시** → [Wiki-Setup.md](./Wiki-Setup.md) 또는 `npm run wiki:push`
